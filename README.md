# expense_tracker
## Project Description

Expense Tracker is a Python-based personal finance management application
that helps users manage their income, expenses, and budgets.

The application allows users to add, view, update, and delete financial
records and export financial data to CSV files.
## Features

- Add and manage expenses
- Add and manage income
- Create and manage budgets
- View financial records
- Update and delete records
- Automatic ID generation
- Export data to CSV files
- Object-oriented project structure
- Exception handling

## Installation / Setup

1. Clone the repository:

   git clone https://github.com/GnapikaBathala/expense_tracker.git

2. Navigate to the project directory:

   cd expense_tracker

3. Make sure Python 3 is installed.

4. Run the application:

   python3 main.py

## How to Run

Open a terminal in the project directory and execute:

python3 main.py
